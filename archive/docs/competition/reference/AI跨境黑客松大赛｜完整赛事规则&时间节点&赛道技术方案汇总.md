## 二、大赛整体赛制（三阶段递进）

本次大赛全程分为：**创意初赛 → 开发复赛 → 决赛路演** 三个阶段，层层递进、逐步落地产品。

### 1\. 创意初赛（核心：提交方案，无需成品）

核心目标：明确业务问题、设计产品功能、搭建AI技术落地路径，重点验证方案价值与可行性，无需开发完整产品。

**提交方式**：官方在线表单填报，无需上传Word、PDF文档。

**表单必填/选填内容**：

- 基础信息：团队名称、队长信息、参赛赛道场景

- 方案名称：自定义作品名称（30字以内）

- 方案概述：业务痛点、目标用户、核心功能、方案亮点、预期效果（1000字以内）

- 技术方案：所用AI模型、工作流、数据处理方式、前后端技术组件（500字以内）

- 附加材料（选填）：产品原型、架构图、流程图、演示截图、视频、代码仓库地址（单文件≤200MB，支持pdf/zip/gz格式）

**初赛评审标准**：优先评估**业务价值、创新性、落地可行性、技术思路完整性**。

**初赛奖励（前100名团队）**：

- 阿里云百炼平台 25000 Credits 算力

- 阿里AI Agent Model Router 2000 credits 额度

### 2\. 开发复赛（核心：落地可演示产品）

**入围名额**：初赛评选前50支团队晋级

**额外奖励**：每队追加阿里云百炼平台 25000 Credits 算力

**作品要求**：具备可演示核心功能，完整跑通核心业务流程，无需达到商用标准，可证明可实现、可使用、具备真实业务价值即可。

**需提交全套材料**：

- 产品功能介绍\+使用说明文档

### 3\. 决赛路演（核心：价值答辩\+商业落地）

**入围名额**：复赛优胜团队晋级现场决赛

**路演形式**：现场产品演示 \+ 评委问答答辩

**提交材料**：完整版可运行Demo、路演PPT、产品商业落地方案

**评审核心维度**：产品完成度、业务落地价值、技术创新性、用户体验、商业可落地潜力。

## 三、三大官方命题赛道（三选一参赛）

### 赛道一：AI 智能上新

**核心任务**：依托AI实现新品选品到店铺上架全流程自动化，将传统数天的上架流程压缩至分钟级。

**可落地细分方向**（任选其一）：

- AI商品图智能生成：自动产出白底图、场景图、模特图、尺寸对比图，适配多跨境平台规范

- AI详情页自动化生成：输入产品卖点，自动图文组合，输出标准化平台详情页

- AI图片本地化适配：自动替换图片背景、文字、模特形象，适配不同国家区域审美

- AI Listing智能写作：多站点、多语言标题、五点描述、搜索关键词本地化改写

- AI商品跨境合规检测：自动排查图片违规风险，输出修改优化方案

**参考技术栈**：阿里云百炼通义万相（图片生成）、通义千问Qwen系列（文案生成）、视觉理解模型（内容合规检测）

### 赛道二：AI 智能营销

**核心任务**：实现跨境营销内容量产、红人匹配、广告投流全链路AI提效，覆盖海外主流社媒与广告渠道。

**可落地细分方向**（任选其一）：

- AI短视频批量生产：自动完成脚本撰写、AI配音、智能剪辑，一键产出成品社媒短视频

- AI社媒文案矩阵：同一产品适配多平台风格，批量生成差异化营销文案

- AI红人智能匹配：根据产品品类、目标市场，精准筛选适配KOL并支持批量触达

- AI广告投放优化：多渠道智能竞价、预算分配、ROAS数据监控与策略调整

- AI自动化邮件营销：新品上新、节日促销、弃购挽回等场景邮件序列自动生成

**参考技术栈**：通义万相（视频生成）、通义千问Qwen系列、TTS/ASR语音模型、Model Router多模型协同

### 赛道三：AI 市场洞察

**核心任务**：搭建跨境卖家专属AI市场情报中心，将海量公开数据转化为可落地的选品、定价、竞争策略。

**可落地细分方向**（任选其一）：

- AI智能选品引擎：扫描多平台数据，挖掘蓝海品类、预判爆款机会

- AI竞品动态追踪：实时监控竞品价格、Listing内容、上新节奏、促销动作

- AI评论深度挖掘：拆解竞品正负向评价，提取用户核心痛点，反向指导产品迭代

- AI智能定价助手：基于竞品价格带、市场热度，输出最优定价与促销方案

- AI跨境合规预警：监控目标市场政策、认证、关税、禁售规则变化，提前风险预警

**参考技术栈**：通义千问Qwen系列、视觉解析模型、DeepSeek/R1趋势推理模型、Model Router API

## 四、官方技术支撑：Model Router API 说明

本次大赛统一使用**阿里云百炼算力平台**，通过 Model Router API 可一站式调用126类AI模型，支持多模型组合开发。

### 1\. 接口基础信息

- Base URL：https://model\-router\.edu\-aliyun\.com/v1

- 认证方式：Bearer Token（API Key，算力审核通过后发放）

- 通用请求头：Authorization: Bearer \<your\-api\-key\>

- 数据格式：Content\-Type: application/json

### 2\. 核心可用模型分类（节选）

|模型类别|代表模型|适用业务场景|
|---|---|---|
|文本对话推理|qwen3\.7\-max、qwen3\.6\-plus、qwq\-plus|文案生成、市场分析、策略推理、方案撰写|
|图片生成|wan2\.7\-image\-pro、wan2\.7\-image|商品图、场景图、营销素材生成|
|视频生成|wan2\.7\-t2v、wan2\.7\-i2v|产品演示视频、社媒短视频自动生成|
|视觉理解|qwen3\-vl\-plus、qwen3\-vl\-flash|商品图解析、Listing视觉分析、素材检测|
|代码模型|qwen3\-coder\-plus、qwen3\-coder\-flash|脚本编写、功能开发、代码调试|
|第三方大模型|deepseek\-v4\-pro、deepseek\-r1、kimi\-k2\.6、glm\-5\.1|长文本分析、深度趋势推理、复杂问题拆解|
|语音模型|qwen\-tts、qwen\-asr|AI配音、字幕生成、语音识别|
|向量排序|text\-embedding\-v4、qwen3\-rerank|语义聚类、关键词挖掘、内容精准匹配|

### 3\. 开发Tips

- 支持**多模型串联组合**：视觉识图→大模型文案生成→TTS配音→视频生成，实现全链路自动化

- 开发建议：先用轻量模型（qwen3\.5\-flash）快速验证原型，决赛前切换高性能模型优化效果

- 展示场景优先使用**流式调用**，提升产品演示体验
