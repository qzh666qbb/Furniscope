## 5. 方案名称

**FurniScope跨境家具超级AI员工**

## 6. 方案概述

**1️⃣ 一句话定义**  
FurniScope 是面向中国跨境家具制造商与中小卖家的“超级 AI 员工”：它把分散的产品图片、规格参数、报价成本、工厂能力、竞品商品和消费者评论，持续转化为有证据、可解释、能落地的市场机会判断与产品迭代建议，让一个用户即可完成过去需要市场、产品、数据和工程团队协作的研究工作。

**2️⃣ 核心功能**  
① **产品与企业能力理解：**解析家具图片、尺寸、材料、结构、功能、成本、包装、认证及工艺约束，形成版本化产品画像和企业能力边界，避免脱离工厂实际能力给出建议。  
② **竞品与市场研究：**围绕目标国家、平台和家具品类，按照价格带、尺寸、材质、结构、风格和使用场景计算竞品可比性，识别市场主流供给、竞争强度、价格分布和差异化空间。  
③ **评论深度挖掘：**从多语言消费者评论中提取舒适度、耐用性、安装难度、气味、尺寸适配、面料触感、包装破损等需求与痛点，形成需求簇、情绪分布和原文证据片段，支持从结论回溯至真实评论。  
④ **机会判断与制造适配：**综合需求热度、竞争缺口、利润空间、趋势信号、证据质量和企业制造适配度，形成六维机会评分、独立置信度及推荐级别，并进一步映射为尺寸、材料、结构、包装和认证建议。  
⑤ **综合决策报告：**自动生成包含市场结论、竞品格局、评论洞察、产品机会、制造适配、工程建议、风险、反证、待验证事项和证据索引的在线报告。

**3️⃣ 方案亮点**  
FurniScope 不是简单生成一段泛化市场摘要，而是把“海外消费者真正需要什么”与“这家企业能不能制造、能不能形成利润”连接起来。用户面对的是一个可自主执行的超级 AI 员工，不需要选择 Agent 或分配岗位；系统内部由多个专业 Agent 协同完成产品理解、市场研究、评论分析、机会评分、工程建议和证据审计，仅在关键事实冲突、样本不足、低置信度或高风险建议时请求用户确认。所有价格、比例、统计指标和机会评分均由确定性程序计算，生成模型只负责语义理解、归纳与推理，降低数据幻觉。每项关键结论均附带证据、置信度、数据范围、评分版本和模型版本，并支持任务幂等、部分失败、自动降级、断点恢复和全链路审计，使 AI 洞察真正具备可解释、可验证、可复用和可落地的业务价值。

## 7. 技术方案说明

FurniScope 采用前后端分离与事件驱动架构。前端使用 React 19、Vite 构建 AI 工作台、新建分析、任务执行、市场洞察、决策报告和管理后台；后端使用 Python FastAPI，按路由、数据模型、服务、仓储和 Agent 适配器分层，提供统一响应、业务错误码、RS256 鉴权、user/admin 权限、租户隔离及持久化幂等。业务数据、任务状态、证据链、模型运行和报告存储于 PostgreSQL；Redis 用于 Worker 运行锁和进度缓存；授权文件进入对象存储，密钥只从环境变量或密钥管理服务读取。

AI 能力统一通过阿里云百炼 Model Router 调用：qwen3-vl-plus 识别家具图片、规格书和包装资料；qwen3.7-max 完成复杂市场推理、机会判断与工程建议；qwen3.6-plus 完成评论结构化抽取、需求归纳和报告组织；text-embedding-v4 以1024维向量完成多语言评论聚类与证据召回；qwen3-rerank 精排竞品候选和证据。Model Router 按任务类型、质量、时延与成本动态选择模型，支持超时重试和降级，模型版本通过管理配置维护，不写死在业务代码中。

数据链路为“产品资料与授权数据导入→校验脱敏和标准化→产品画像→竞品可比性计算→评论证据抽取与聚类→价格及竞争指标确定性计算→六维机会评分→企业制造适配→工程建议→证据审计→在线报告”。LangGraph 编排产品理解、数据质量、竞品发现、评论洞察、机会评分、企业适配、建议和报告审计节点，并行处理竞品与评论。

对用户仅展示“理解产品、研究市场、评估机会、生成建议、完成报告”五个阶段。系统默认自主执行和自动重试；遇到事实冲突、样本不足、低置信度或高风险建议时触发统一用户确认，保存 Checkpoint，回答后通过 LangGraph 恢复。成功节点利用输入版本哈希和数据库唯一约束保证幂等，避免重复调用、计费或覆盖证据；部分数据源失败时保留可用结果并说明影响。系统记录模型、Prompt、Token、耗时、输出校验、证据引用和数据快照，实现可信、可恢复、可审计的市场洞察闭环。
