# Archive

本目录保存已被替代、已完成使命或仅用于追溯的历史材料，不参与当前应用的构建、运行、测试或正式交付。

- `docs/`：历史文档、赛事阶段材料、提示词和迭代计划，详见 [`docs/README.md`](./docs/README.md)。
- `ui-design-v1/`：第一版 UI 设计和 React 导出稿。
- `ui-design-v2/`：第二版 UI 设计文档和 PDF。
- `product-design-prototype/`：早期产品设计插件生成的前端快照。

当前有效文档从 [`../Docs/README.md`](../Docs/README.md) 进入，当前唯一维护的前端位于仓库根目录 `frontend/`。

## 归档规则

1. 归档内容只读保留，不作为当前需求、接口、部署或评审依据。
2. 需要恢复时移动回原目录，并同步修复索引和相对链接。
3. 不把密钥、账号、数据库备份和未脱敏业务数据移入归档；此类内容继续按安全策略排除。
4. 同一材料存在可确认的重复副本时仍暂不删除，在归档清单中标记重复关系。
