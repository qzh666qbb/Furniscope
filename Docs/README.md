## 维护规则

1. `Docs/参赛提交决赛/` 只保留决赛正式材料、直接素材和一份截图索引。
2. 当前文档被新版本替代后，应移动到相应归档目录并更新本导航。
3. 提示词、待办、阶段性差距分析和一次性实施计划不放入当前文档区。
4. Markdown 是可维护源文件，Word 是编辑版本，PDF 是正式交付版本；内容变更后应同步生成。
