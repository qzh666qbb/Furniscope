## 维护口径

1. 决赛入围定稿 DOCX 是三份配套说明的权威内容来源。
2. 修改主文档后，应重新生成本目录内对应 PDF，避免 Word 与 PDF 内容不一致。
3. 本目录不保存带时间戳的过程备份、中间重写稿或机器生成的 JSON/SHA 清单。
4. 旧阶段材料保留在 [`../参赛提交/`](../参赛提交/)；当前评审统一从本目录读取。
