# FurniScope 跨境家具超级 AI 员工

## 项目概览

FurniScope 参加“赛道三：AI 市场洞察”。它面向缺少数字化市场研究团队的跨境家具制造商，将产品资料、企业制造约束、竞品商品和消费者评论连接起来，由一个超级 AI 员工自主完成市场研究、竞品分析、评论洞察、机会判断、产品建议和证据化报告。

代码仓库：https://github.com/qzh666qbb/Furniscope

## 业务闭环

1. 用户输入目标市场并提供产品、企业能力和授权市场数据。
2. AI 建立产品画像，检查数据质量并发现可比竞品。
3. AI 从评论中提取消费者需求、痛点、情绪与原文证据 Span。
4. 确定性程序计算价格、比例、竞争指标和六维机会评分。
5. AI 将机会与企业材料、工艺、成本、包装和认证能力进行适配。
6. 系统输出结论、置信度、工程建议、风险、待验证事项及证据索引。

默认自主执行；仅在关键事实冲突、样本不足、低置信度或高风险建议时触发 `user_confirmation`，通过 LangGraph Checkpoint 安全恢复。

## 技术架构

- 前端：React 19 + Vite。
- API：Python FastAPI，统一 Envelope、RS256 鉴权、租户上下文和持久化幂等。
- Agent：LangGraph，内部专业节点、并行 Map/Reduce、自动重试、降级、部分失败和断点恢复。
- AI：阿里云百炼 Model Router；视觉理解、文本推理、Embedding 与 Rerank 按任务路由。
- 数据：PostgreSQL 保存业务事实、证据、模型运行、任务状态和 Checkpoint 投影；Redis 保存运行锁和短期缓存；对象存储保存授权原始文件。
- 安全：密钥只从环境变量读取；用户数据按 `tenant_id` 隔离；不在日志中记录密码、Token、API Key 或评论全文。
