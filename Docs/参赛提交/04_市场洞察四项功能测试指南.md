# 市场洞察两项功能测试指南

> 适用项目：FurniScope 跨境家具超级 AI 员工  
> 适用页面：市场洞察 → 竞品分析与评论舆情  
> 更新日期：2026 年 9 月 14 日

本文档提供竞品分析和评论舆情两组可操作测试案例。评论采集已并入「评论舆情」，不再单独测试主动采集；政策预警不作为产品功能。建议先导入同一份市场数据集，再执行竞品对照。

## 一、测试前准备：导入市场数据集

进入“市场洞察”，点击“导入数据”，填写以下内容：

| 字段 | 填写内容 |
|---|---|
| 数据集名称 | 美国沙发功能测试 |
| 平台 | amazon |
| 目标市场 | 美国（US） |
| 品类 | sofa |
| 来源类型 | 企业授权导出 |
| 来源名称 | FurniScope 功能测试 |
| 数据日期 | 2026-09-14 |

上传测试文件：

- [market_insights_test_v1.json](../../demo_data/market_insights_test_v1.json)

### 预期结果

- 竞品数量为 1。
- 原始评论数量为 4。
- 有效评论数量为 2。
- 过滤评论数量为 2。
- 过滤原因包含重复评论和无意义短评。
- 数据集状态变为“可用于分析”。

## 二、案例一：竞品价格、Listing 与促销变更

### 1. 建立监控目标

进入“竞品分析”，选择一个**本企业产品**（产品中心中的 SKU，不要把 `SYN-HF-*` 当竞品），然后：

- 点击「匹配相似竞品」，系统按标题相似度把外部 Listing **写入竞品库**；或
- 点击「从市场数据加入」，在已导入商品中搜索并加入竞品库；或
- 粘贴 Amazon 等竞品商品页网址，点击「采集并加入对比」。

竞品库支持勾选参与对比，以及从列表中删除（停止监控，历史快照保留）。

也可以在「手工填写外部 ASIN」中填入市场上的 `TEST-SOFA-001`（不要填本企业 SKU），然后点击「刷新快照」。

### 2. 检查初始数据

初始商品信息应为：

| 项目 | 初始值 |
|---|---|
| 商品标题 | Demo Modular Sofa 3 Seat |
| 售价 | USD 429 |
| 划线价 | USD 499 |
| 商品编号 | TEST-SOFA-001 |

完成刷新后，系统应形成第一个 Listing 快照。

### 3. 制造一次竞品变更

返回市场数据集列表，对“美国沙发功能测试”执行“重新上传”，上传：

- [market_insights_test_v2.json](../../demo_data/market_insights_test_v2.json)

上传完成后返回“竞品分析”，点击“立即刷新快照”。

### 4. 预期结果

- 售价从 USD 429 变为 USD 389。
- 标题变为 `Demo Modular Sofa 3 Seat - New Fabric`。
- 材质从 `linen` 变为 `performance linen`。
- 新增促销字段 `Autumn Deal`。
- “价格趋势”展示价格变化。
- “版本对比”展示标题、价格和属性差异。
- “上新与促销”展示上架与促销覆盖。

## 三、案例二：评论舆情与自动情感识别

### 1. 获取舆情

进入：

```text
市场洞察 → 竞品分析与评论舆情 → 评论舆情
```

粘贴评论页网址：

```text
https://www.amazon.com/product-reviews/B0D4KLHDH8
```

点击「获取舆情」。不需要上传 JSON，也不需要单独进入主动采集页。

### 2. 预期结果

- 列表同时展示已导入数据集中的有效评论，以及本次网页采集的新事件。
- 顶部正向 / 负向 / 中性数字来自当前筛选的全量统计，不是当前页条数。
- 情感筛选与搜索框在卡片标题右侧同一行。
- 选择「负向」后只显示负面评论。
- 选择了市场数据集时，采集结果会写入该数据集，供 AI 分析复用。
- 同一页面重复获取时，相同评论不会重复写入。

Amazon 可能返回验证码或访问限制页面。如果获取数量为 0，可以替换为浏览器中能够正常打开的 Amazon 商品评论页：

```text
https://www.amazon.com/product-reviews/真实ASIN
```

## 五、问题排查建议

### 竞品分析没有曲线

- 确认监控商品编号与数据集中的 `platform_listing_id` 完全一致。
- 至少需要两个不同时间或不同价格的快照才能形成明显曲线。
- 重新上传 V2 文件后再次点击“立即刷新快照”。

### 评论舆情没有数据

- 确认所选数据集本身有评论正文；只有列表演示、没有导入文件的档案不会出现评论。
- 先在普通浏览器中确认目标地址能够打开。
- 检查目标页面是否返回验证码或 JavaScript 动态内容。
- 查看提示中的失败原因。

### 评论事件重复推送仍新增

- 确认 `external_id`、评论正文和评论时间没有变化。
- 检查正文是否包含额外空格或动态内容。
