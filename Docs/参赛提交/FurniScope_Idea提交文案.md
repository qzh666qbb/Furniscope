## 5. 方案名称

**FurniScope跨境家具超级AI员工**

## 6. 方案概述

**1️⃣ 一句话定义**  
FurniScope 面向缺乏数字化市场研究团队的跨境家具制造商，把分散的产品资料、企业制造能力与目标市场数据转化为可追溯的选品和产品迭代决策，让一个用户即可完成过去需要市场、产品、数据和工程人员协作的研究工作。

**2️⃣ 核心功能**  
① 产品与企业能力理解：解析商品图片、尺寸、材料、结构、成本及包装约束，形成版本化产品画像；② 竞品与市场研究：按家具品类、价格带、尺寸、材质和使用场景筛选可比竞品，分析价格与竞争格局；③ 评论深度挖掘：从多语言评论中提取舒适度、耐用性、安装、气味、尺寸、包装等需求与痛点，并保留原文证据片段；④ 机会判断：结合需求热度、竞争缺口、利润空间、趋势、证据质量和企业制造适配度，输出六维机会评分与置信度；⑤ 决策报告：生成包含产品建议、制造适配、风险、待验证事项和证据索引的在线报告。

**3️⃣ 方案亮点**  
不是生成泛化市场摘要，而是将“外部市场真实声音”与“这家工厂能否制造、能否盈利”连接起来；用户面对的是一个可自主执行的超级 AI 员工，系统仅在事实冲突、样本不足、低置信度或高风险建议时请求确认。所有价格、比例和评分由确定性程序计算，AI 负责理解和推理；结论附证据、置信度、数据范围和模型版本，支持部分失败、断点恢复与全链路审计，降低幻觉和重复调用成本。

## 7. 技术方案说明

系统采用 React 19 + Vite 前端、FastAPI 服务层、LangGraph 多 Agent 工作流、PostgreSQL、Redis及对象存储。通过阿里云百炼 Model Router 调用：`qwen3-vl-plus` 解析家具图片和规格，`qwen3.7-max` 负责复杂市场推理与建议，`qwen3.6-plus` 负责结构化抽取和报告组织，`text-embedding-v4`（1024维）完成评论聚类与证据召回，`qwen3-rerank` 重排证据和竞品候选；模型按质量、成本和时延动态路由。数据链路为“资料与授权数据导入→校验标准化→产品画像/竞品匹配→评论证据抽取与聚类→确定性指标及六维机会评分→企业制造适配→证据审计→在线报告”。LangGraph 提供并行执行、自动重试、部分失败、用户确认和 Checkpoint 恢复；模型运行全程记录版本、Token、耗时及 Schema 校验，API Key 仅从环境变量读取。
