## 维护规则

1. 本目录不存放提示词、待办、缺口分析、旧版 UI 或初赛附件。
2. 截图使用脱敏后的当前运行界面，不使用旧设计稿冒充实际页面。
3. Markdown 内容更新后应重新生成对应 Word/PDF，避免交付版本滞后。
4. 最终 PDF、演示视频和 Demo ZIP 生成后应使用明确的团队名、方案名和版本号命名。
