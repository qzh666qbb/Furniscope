
# 本地调试排错全套提示词模板
分4种场景：通用报错、后端(FastAPI/LangGraph)报错、数据库报错、前端(React)报错，直接复制，粘贴**报错日志 + 对应代码片段**即可。

> 使用小技巧：尽可能贴完整控制台报错栈，不要只贴一句报错；同时带上对应的设计文档片段（数据库字段/Agent工作流/API文档），AI修复不会偏离设计。

## 模板1｜通用全局排错（不知道哪里出问题优先用这个）
```
你现在是调试工程师，我在运行本跨境家具AI项目Demo时出现报错。
项目技术栈：FastAPI + PostgreSQL + LangGraph + React 19 + Vite，严格遵循之前全套设计文档，不要擅自改动业务逻辑、字段、状态定义。
下面是完整报错日志和相关代码片段：
【粘贴控制台完整报错日志】
【粘贴出错的代码片段】

请完成：
1. 定位根因，用简短文字说明为什么报错；
2. 给出修复后的完整代码片段；
3. 说明修改点，标注改动了哪些地方；
4. 如果需要修改配置、环境变量、数据库数据，请一并给出；
5. 给出验证修复是否生效的操作步骤。
禁止大改业务，尽量最小改动修复bug。
```

## 模板2｜后端专项排错（FastAPI、LangGraph Agent、Model Router大模型调用报错）
```
你是后端调试工程师，本项目基于FastAPI、LangGraph实现Agent工作流，对接阿里云Model Router，严格对齐项目Agent工作流文档、API接口文档、数据库表结构。
运行后端服务发生异常，报错信息与相关代码如下：
【粘贴完整Traceback报错堆栈】
【粘贴出错Python代码】

排查方向重点关注：
‑ LangGraph节点状态传递、分支判断、任务状态枚举是否和文档一致
‑ 异步上下文、数据库session会话释放问题
‑ Model Router请求参数、超时、鉴权、异常捕获逻辑
‑ API入参校验、返回体结构、业务错误码

输出：根因分析，最小改动修复代码，改动说明，验证步骤。不要变更原有业务流程。
```

```
你是数据库工程师，项目使用PostgreSQL，严格按照之前的数据字典、建表结构文档。
执行SQL / 程序操作数据库时报错。
报错日志：
【粘贴报错】
相关SQL/代码：
【粘贴SQL或者ORM代码】

重点排查：字段名、表名大小写、约束、外键、枚举值、索引是否与设计文档一致。
输出：根因，修正后的SQL/代码；如果需要执行更新SQL，给出可直接执行语句；说明如何验证。
不擅自新增表和字段。
```

## 模板4｜React前端排错（控制台JS报错、接口请求、状态渲染、页面异常）
```
你是React前端工程师，严格依据页面交互原型文档、后端API接口契约和现有UI_V2 React组件。
前端页面出现问题，可以是JS报错、渲染异常、接口请求失败、状态异常。
浏览器Console报错：
【粘贴浏览器控制台报错】
相关React组件代码：
【粘贴.jsx/.tsx代码片段】

排查重点：
‑ fetch请求路径、请求体格式是否匹配后端API
‑ loading、空状态、错误状态处理逻辑
‑ React Hooks依赖、状态更新、闭包和组件生命周期问题
‑ 接口返回数据字段和前端使用字段是否对齐

输出：根因，修复后的完整组件片段，改动点说明，验证操作步骤。
```

## 模板6｜业务逻辑异常（代码不报错，但是业务行为不对，Agent流转不对、返回结果不符合预期，无崩溃报错）
> 非常高频：不抛异常，但是Agent流程不走分支、任务状态不对、输出结果错误
```
本项目运行没有抛出崩溃报错，但是业务行为不符合设计文档预期。
现象描述：【详细写发生了什么，期望应该发生什么】
相关代码片段：
【粘贴Agent/API代码】
参考文档片段：【粘贴Agent工作流/API文档对应部分】

请对比设计文档，找出逻辑偏差；给出最小修改方案，输出修复代码，说明修改点，以及复现验证步骤。禁止改变原始业务设计。
```

## 模板7｜快速复现&自测提示词（修复完bug后使用）
```
已经完成bug修复，请帮我写一段简短的复现步骤，我本地手动操作验证该问题已经解决，同时确认没有破坏其他原有业务流程。
```
