# FurniScope 管理后台设计

## 产品边界

管理后台仅供平台管理员使用。普通用户均为企业客户；每个企业用户在开户时获得独立租户、登录账号、业务数据空间和预测模型部署。

后台只保留两个一级模块：

1. 企业用户
2. 预测模型

数据源、SKU、Prompt、通用模型路由和工作流诊断不作为一级管理导航。

## 企业用户

列表将企业租户和主要登录账号合并展示，包括企业名称、租户编码、账号状态、功能授权、当前模型和最近登录。

开户一次完成租户、企业账号、功能授权和基础模型分配。用户换企业不直接修改租户归属，应停用旧账号并在新租户重新开户。

管理员可暂停或恢复企业。暂停同时阻止企业登录和新任务，不删除历史数据。

## 预测模型

模型按租户管理。列表展示企业当前版本、数据截止日期、SKU 数、最近训练和部署状态。

更新流程为：上传企业订单与库存数据、租户范围校验、追加去重、重新训练、校验、原子发布。失败继续使用原版本。

版本历史保留企业私有模型与基础模型部署记录，允许管理员显式回滚；已创建的预测任务继续使用创建时冻结的部署。

## 安全约束

- 浏览器提交的租户范围不能作为可信身份来源。
- 文件、任务、SKU、训练制品和模型部署全部带 `tenant_id`。
- 平台管理员使用独立登录入口，企业登录入口拒绝管理员身份。
- 开户、授权、暂停、训练、发布和回滚写入审计日志。
- 页面不展示模型文件路径、密钥或其他企业的业务正文。
