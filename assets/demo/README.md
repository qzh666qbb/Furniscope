# 演示视频

将产品演示视频放到本目录，文件名固定为：

```text
assets/demo/FurniScope-产品演示.mp4
```

仓库内相对路径（克隆后本地打开）：

```text
./assets/demo/FurniScope-产品演示.mp4
```

GitHub 在线地址（推送后可用）：

https://github.com/qzh666qbb/Furniscope/blob/main/assets/demo/FurniScope-产品演示.mp4

GitHub 单文件上限约 100 MB。超过请先用 Git LFS 跟踪该 mp4，再推送。不要把密钥、未脱敏业务数据或后台录屏里的管理员口令编进视频。
